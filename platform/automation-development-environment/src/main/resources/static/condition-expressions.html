Expressoes de condicao BPMN para e-mails

As condicoes de branch sao avaliadas pelo Camunda quando o processo passa por um gateway exclusivo. Em respostas de e-mail, o CIR entrega ao processo a variavel body com o corpo da mensagem.

Padrao gerado pelo ADE

Quando uma branch tem texto BPMN, mas ainda nao tem uma condicao, o ADE gera uma expressao que procura esse mesmo texto no corpo do e-mail sem diferenciar maiusculas e minusculas. 

${body != null && body.toLowerCase().contains("confirmado")}

Exemplo: se o texto da branch for confirmado, a resposta sera aceita quando o corpo do e-mail contiver confirmado, Confirmado ou CONFIRMADO.

Exemplos uteis

${body != null && body.toLowerCase().contains("aprovado")}
${body != null && body.toLowerCase().contains("recusado")}
${body != null && body.toLowerCase().contains("dados complementares")}

Boas praticas

  • Use textos curtos e objetivos na branch, como confirmado, aprovado ou recusado.
  • Configure uma branch default para tratar respostas que nao correspondam a nenhuma condicao.
  • Mantenha o identificador CORRELATION-ID no assunto ou corpo do e-mail para permitir a correlacao da resposta.
