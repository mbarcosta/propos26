# ADR-005: Create Automation Development Environment

Status: PROPOSED

## Decision

Create ADE as the central user-facing development environment for automations.

## Rationale

The target user should be able to move from BPMN to executable automation through assisted configuration and generation, not by manually wiring every integration.

## Consequences

ADE becomes responsible for project metadata, BPMN editing, requirement analysis, capability lookup, deployment coordination, testing, and monitoring.
