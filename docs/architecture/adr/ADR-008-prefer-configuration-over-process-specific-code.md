# ADR-008: Prefer Configuration Over Process-Specific Code

Status: PROPOSED

## Decision

Prefer configuration over process-specific code for bindings, events, messages, correlations, topics, endpoints, templates, and deployment parameters.

## Rationale

The propos26 goal is to reduce manual programming when creating new automations.

## Consequences

GMS and CIR must progressively replace hard-coded process rules with ADE-managed configuration.
